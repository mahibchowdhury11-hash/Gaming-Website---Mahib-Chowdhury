Gameplay

Brawlhalla is a really popular game with millions of players. Brawlhalla is a multiplayer and/or singleplayer platformer game. There are many modes like ranked 1v1, 2v2s, more. Also there is local so if you have an extra controller or a you have a nintendo switch you can play with a friend. In this game there are are about 70 characters which are called legends. Many many more legends will be released but almost every legend is pretty unique. This game is pretty fun in general and has really cool movement styles and fighting system. This game has some inspiration from Super Smash bros. Even though the game looks pretty similar to Smash Bros, the game is still really different from Smash Bros only keeping some of the cool things like the health system from Smash Bros. Anyways I think that both games are amazing. I would probably recommend this game if you want something to play casually or you want a game to get good at.

Getting into the Game

I have lots of hours on this game but I wouldn't consider myself good, it takes lots of time or some coaching to become good at this game. Like if you are just playing it and you don't know what your doing then you won't get much better as fast. Like I had 200 hours on the game before but I was just playing random stuff on the game. So if you want to get good at this game you should probably use Youtube videos or a friend who is experienced at this game. But in general you will get better overtime if you just keep playing this game.
