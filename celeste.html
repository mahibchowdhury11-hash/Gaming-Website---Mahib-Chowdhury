Celeste

Gameplay

Celeste is a singleplayer game where the goal is to get to the top of the mountain. The game is really cool and the movement is simple, but you're going to need to practice it a lot if you want to beat the game. This game is really good but still isn't too popular standing at 6.1 million players, but this month Oct 30, 2026 it has averaged about 2250 players. Personally I would recommend this game because it is a really nice game.
